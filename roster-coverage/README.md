# Roster Coverage and Overtime Report

A small Python script that reads a weekly shift roster CSV and reports:

- **Hourly coverage.** Headcount for every operating hour, per location and day, flagging any hour below a minimum you set.
- **Weekly hours.** Hours per employee, with anyone over 40 flagged for overtime (the threshold is configurable).
- **Summary report.** A `summary.md` that groups understaffed hours into time windows and lists overtime and any rows it had to skip.

It uses only the Python 3 standard library, so there's nothing to install.

## Usage

```bash
python3 roster_coverage.py sample_input.csv --out output --min-staff 3
```

```
116 shifts read, 0 skipped | 46 understaffed hours | 2 employee(s) over 40 h
Wrote output/coverage.csv, output/hours.csv, output/summary.md
```

| Option | Default | Meaning |
|---|---|---|
| `--min-staff N` | 3 | Minimum people needed each hour |
| `--ot-threshold H` | 40 | Weekly hours before overtime |
| `--open-hour` / `--close-hour` | from data | Set the operating window yourself instead of taking it from the earliest start and latest end |
| `--out DIR` | `output` | Where the output files go |

**Input columns:** `employee, role, date, start, end, location`. Dates are `YYYY-MM-DD`. Times can be `14:00`, `2:00 PM` or `1400`. Overnight shifts such as `22:00`–`06:00` are handled. Bad rows are skipped and listed in the report, so one bad row doesn't stop the run.

**Counting rule:** someone counts toward an hour if they work at least 30 minutes of it. A 10:30 start counts for 10:00, but an 11:45 finish doesn't count for 11:00.

## Files

- `roster_coverage.py`: the tool
- `make_sample.py`: generates `sample_input.csv` (25 made-up employees, a seeded random week)
- `sample_input.csv`: sample input
- `output/`: files produced from the sample input
- `tests/test_roster_coverage.py`: unit tests

## Tests

```bash
python3 -m unittest discover -s tests -v
```

The six tests cover headcount and gap flags, the 30-minute rule, overtime, overnight shifts, bad-row handling, and a full run on the sample file.

## Data

All names and shifts are synthetic, generated by `make_sample.py`. They don't come from any real business or roster.
